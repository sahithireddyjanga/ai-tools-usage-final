AI TOOLS USAGE PROJECT - STEP 3 FILES

Included:
- AI_Tools_Usage_Dashboard_Dataset.xlsx : original dataset workbook
- data_dictionary.csv                  : dataset column descriptions
- clean_dataset.csv                    : cleaned dataset
- scripts/data_cleaning.py             : cleaning program
- scripts/data_analysis.py             : descriptive and grouped analysis
- scripts/data_visualisation.py        : multiple chart types
- outputs/                             : analysis CSV files and generated charts

NOT INCLUDED:
- Project proposal
- Power BI (.pbix) dashboard

HOW TO RUN (from this folder):
1. Install Python.
2. Open Command Prompt/Terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: python scripts/data_cleaning.py
5. Run: python scripts/data_analysis.py
6. Run: python scripts/data_visualisation.py

Charts include histogram, bar chart, scatter plot, box plot, violin plot,
pie chart and correlation heatmap.
